# DataEntropy

DataEntropy is a practical learning platform for data courses, career roadmaps,
interview preparation, webinars, and one-to-one mentor sessions.

The app uses the existing Supabase project so current content, users, bookings,
and admin workflows continue to work without a data migration.

## Local development

```sh
npm install
npm run dev
```

## Production

Build with `npm run build` and deploy the generated Vite app to Vercel. The
included `vercel.json` preserves client-side routes on direct navigation.
