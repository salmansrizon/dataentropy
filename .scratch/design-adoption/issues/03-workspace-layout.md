## Question

How should the shared design adapt to dense CareerPrep and coding workflows, including editor typography, split panes, results, long content, keyboard operation, and mobile use, without removing existing actions?

## Answer

CareerPrep and coding workspace retain dense functional layouts and existing Monaco/editor sizing. Shared tokens supply typography, surfaces, borders, focus rings, status colors, and responsive spacing. Long content must scroll within its existing regions; keyboard and touch actions remain native. No editor-specific visual rewrite is needed until browser review identifies a concrete failure.
